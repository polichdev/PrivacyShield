# Security Policy

## Reporting a Vulnerability

Privacy Shield is built to protect user privacy and network integrity. We take security vulnerabilities seriously.

If you discover a security issue or potential vulnerability (such as DNS parsing vulnerabilities, tunnel bypass vectors, or improper intent exposures):

1. **Do not open a public issue.**
2. Send a detailed report describing:
   - Type of vulnerability and potential impact.
   - Exact steps or proof-of-concept to reproduce the behavior.
   - Affected versions and device/Android environment.
3. We will acknowledge receipt within 48 hours and work with you on a coordinated fix and disclosure.

For full architectural details on our security architecture, see [docs/SECURITY.md](docs/SECURITY.md).
